
If you want to retrieve the unique templates generated by Drain3 that have been recorded in OpenSearch, you can use an aggregation on the `drain_template` or `drain_template.keyword` field.

```
curl -X POST "http://localhost:9200/logs-anomalies/_search" -H "Content-Type: application/json" -d '{ "size": 0, "aggs": { "plantilles_drain3": { "terms": { "field": "drain_template.keyword", "size": 50 } } } }' | jq .
````

If you want to view the latest stored documents, showing only the fields related to Drain3 (cluster ID, template, and original message):

```
curl -X POST "http://localhost:9200/logs-anomalies/_search" -H "Content-Type: application/json" -d '{ "size": 10, "_source": ["drain_cluster_id", "drain_template", "drain_cluster_size", "message"] }' | jq .
```
